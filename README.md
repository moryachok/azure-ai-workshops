# Azure AI Workshops

This repository provides hands-on, step-by-step guidelines for various topics in the AI domain.

### [Workshop 1: Advanced RAG with Azure AI Search and Microsoft Foundry ](./rag-workshop/README.md)

In this workshop, you'll explore how to build end-to-end RAG (retrieval augmented generation) Agents sugin Azure AI Search and Microsoft Foundry. Through the guided labs, you’ll learn how to build end-to-end data ingestion and retrieval pipelines. You will ingest multiple data formats such as DOCX and CSV, apply advanced chunking strategies and explore search and retrieval techniques including vector search, filters, and semantic ranking, and finally connect Azure AI Search to a Foundry Agent Service to power question answering with real data. By the end of the workshop, you’ll have practical experience setting up the required Azure resources, understanding core search assets, and integrating search into an AI application, along with sample code to extend the solution further.

The expected duration for the entire workshop is approximately **2 hours**.

[Start the workshop.](./llm-evaluation-workshop/README.md)

### [Workshop 2: Evaluate your LLM application with Azure AI Foundry](./llm-evaluation-workshop/README.md)

In this workshop, you'll explore how to evaluate Large Language Models (LLMs) using [Azure AI Foundry](https://azure.microsoft.com/en-us/products/ai-foundry). By the end of this session, you'll be equipped with hands-on experience in setting up and evaluating your LLM model quality using different evaluation technics and tools.
To learn more about LLM evaluation visit evaluations [official documentation](https://learn.microsoft.com/en-us/azure/ai-studio/concepts/evaluation-approach-gen-ai).

The expected duration for the entire workshop is approximately **2 hours**.

[Start the workshop.](./llm-evaluation-workshop/README.md)
